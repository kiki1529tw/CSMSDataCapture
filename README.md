# CSMSDataCapture

#### 使用步驟
##### Step 1: 
在chrome extensions找到Tampermonkey篡改猴並安裝
[篡改猴連結](https://chromewebstore.google.com/detail/%E7%AF%A1%E6%94%B9%E7%8C%B4/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=zh-TW)
於瀏覽器右上方的擴充功能 > 竄改猴 > 更多選項 > 管理擴充功能 > 開啟【允許使用者指令碼】

##### Step 2: 
請點擊下方連結安裝Tampermonkey腳本
[安裝連結](https://github.com/kiki1529tw/CSMSDataCapture/raw/refs/heads/main/loader.user.js)
點擊後會自動開啟Tampermonkey腳本安裝頁面
點選【安裝】
即可開始使用
